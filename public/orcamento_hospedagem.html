Orçamento de hospedagem

Onde o site está publicado, por que escolhemos assim e quanto custaria em outras opções.

Onde o site está hoje

O Bolso Coletivo está publicado na Railway, que serve a pasta public/ como site estático, com HTTPS e o domínio próprio pequenosvalores.site. A cada mudança aprovada no GitHub, o site é publicado de novo, sem passo manual. As notícias do dia são atualizadas por uma tarefa automática no GitHub Actions, que é gratuita.

Do que o site precisa

  • Site estático (cerca de 4 MB de páginas e imagens), sem banco de dados, com HTTPS.
  • Uma tarefa automática por dia, para as notícias.
  • Custo zero ou muito baixo, porque é um projeto educativo.

Por que hospedagem estática

  1. Custo: o site não precisa de servidor de aplicação nem de banco de dados, então não faz sentido pagar por eles.
  2. Encaixe técnico: site estático, HTTPS automático e GitHub Actions gratuito para as notícias.
  3. Fluxo de trabalho: publicação automática a partir do GitHub, com histórico de versões.
  4. Sustentabilidade: site leve, sem servidor dedicado, imagens em WebP e sem rastreadores.

Se o projeto precisar enviar o formulário de verdade, ter login ou banco de dados, a migração indicada é para uma hospedagem compartilhada, como HostGator ou Hostinger.
